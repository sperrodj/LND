# Unidad 9. CSS: presentación y diseño adaptable

CSS permite controlar la presentación visual de los documentos HTML: colores, tipografías, espacios, tamaños, alineación y distribución de los elementos. También permite adaptar una misma página a pantallas, preferencias y dispositivos diferentes.

```text
HTML → estructura y significado
CSS  → presentación y distribución
```

## Resultados de aprendizaje

Al terminar la unidad, el alumnado podrá:

- Vincular correctamente hojas de estilo con documentos HTML.
- Escribir reglas CSS válidas y organizadas.
- Seleccionar elementos mediante selectores básicos y combinadores.
- Explicar la cascada, la herencia y la especificidad.
- Utilizar colores, tipografías, fondos, unidades y variables.
- Aplicar correctamente el modelo de cajas.
- Construir distribuciones con Flexbox y Grid.
- Diseñar páginas adaptables mediante media queries.
- Respetar preferencias de accesibilidad y movimiento.
- Depurar CSS utilizando las herramientas del navegador.
