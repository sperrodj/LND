# Unidad 7. Almacenamiento, formatos de intercambio y XQuery

## Presentación

XML no solo permite representar información. También puede utilizarse para intercambiarla, almacenarla, consultarla y transformarla.

En esta unidad estudiaremos:

- Diferentes formas de almacenar documentos XML.
- Bases de datos XML nativas.
- Formatos habituales de intercambio de información.
- BaseX como sistema gestor de documentos XML.
- XQuery como lenguaje de consulta.
- Expresiones FLWOR.
- Creación de nuevos documentos a partir de datos existentes.

## Resultados de aprendizaje

Al finalizar la unidad, el alumnado deberá ser capaz de:

- Diferenciar almacenamiento en archivos, bases relacionales y bases XML nativas.
- Elegir un formato de intercambio según el contexto.
- Comparar XML, JSON, CSV y YAML.
- Crear y gestionar una base de datos XML con BaseX.
- Consultar documentos mediante XQuery.
- Utilizar XPath dentro de XQuery.
- Construir consultas FLWOR.
- Filtrar, ordenar, agrupar y calcular resultados.
- Generar HTML, XML, texto y JSON desde XQuery.
- Aplicar operaciones básicas de actualización de forma controlada.
