# Unidad 6. Sindicación de contenidos: RSS y Atom

## Presentación

La sindicación permite publicar novedades en un formato estructurado para que otras aplicaciones puedan detectarlas, descargarlas y mostrarlas automáticamente.

En esta unidad aprenderemos a crear, interpretar, comprobar y publicar canales RSS 2.0 y Atom 1.0.

## Resultados de aprendizaje

Al finalizar la unidad, el alumnado deberá ser capaz de:

- Explicar qué es la sindicación de contenidos.
- Reconocer los usos reales de RSS y Atom.
- Diferenciar una página web de un canal de sindicación.
- Crear canales RSS 2.0 bien formados.
- Crear documentos Atom 1.0 utilizando su espacio de nombres.
- Utilizar fechas, identificadores y enlaces correctamente.
- Incluir contenido HTML sin romper el XML.
- Comprobar los documentos con herramientas de validación.
- Comparar RSS 2.0 y Atom 1.0.
- Publicar un canal y enlazarlo desde una página HTML.

## Idea principal

```text
Sitio web → publica un canal XML → lector se suscribe → recibe novedades
```

RSS y Atom no sustituyen una página web. Proporcionan una versión estructurada y actualizable de sus novedades.
