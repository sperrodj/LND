# 3. Atom 1.0

## 3.1. ¿Qué es Atom?

Atom 1.0 es un formato XML de sindicación diseñado para describir canales y entradas de manera precisa.

Su estructura general es:

```text
feed
├── información general
├── entry
├── entry
└── ...
```

- `feed` representa el canal.
- `entry` representa cada publicación.

## 3.2. Espacio de nombres

El elemento raíz debe declarar el espacio de nombres de Atom:

```xml
<feed xmlns="http://www.w3.org/2005/Atom">
```

Es un espacio de nombres predeterminado. Esto significa que `feed`, `title`, `entry` y los demás elementos sin prefijo pertenecen a Atom.

No debe omitirse:

```xml
<!-- Incorrecto como documento Atom -->
<feed>
```

```xml
<!-- Correcto -->
<feed xmlns="http://www.w3.org/2005/Atom">
```

## 3.3. Estructura mínima

```xml
<?xml version="1.0" encoding="UTF-8"?>
<feed xmlns="http://www.w3.org/2005/Atom">
  <title>Horizonte Científico</title>
  <id>https://example.com/atom.xml</id>
  <updated>2026-11-18T12:30:00Z</updated>
</feed>
```

Elementos esenciales:

| Elemento | Función |
|---|---|
| `title` | Nombre del canal |
| `id` | Identificador permanente |
| `updated` | Última actualización |

## 3.4. Primer canal con entradas

```xml
<?xml version="1.0" encoding="UTF-8"?>
<feed xmlns="http://www.w3.org/2005/Atom">
  <title>Horizonte Científico</title>
  <subtitle>Divulgación sobre ciencia, tecnología y medioambiente</subtitle>
  <link href="https://example.com/"/>
  <link
    rel="self"
    href="https://example.com/atom.xml"
    type="application/atom+xml"/>
  <id>https://example.com/atom.xml</id>
  <updated>2026-11-18T12:30:00Z</updated>

  <author>
    <name>Equipo de Horizonte Científico</name>
  </author>

  <entry>
    <title>Nuevos avances en energía solar</title>
    <link href="https://example.com/energia/avances-solar"/>
    <id>https://example.com/entradas/energia-solar-001</id>
    <updated>2026-11-18T09:30:00Z</updated>
    <summary>
      Explicamos cómo mejoran la eficiencia los nuevos materiales fotovoltaicos.
    </summary>
  </entry>
</feed>
```

## 3.5. Identificadores con `id`

Cada canal y cada entrada deben tener un identificador estable:

```xml
<id>https://example.com/atom.xml</id>
```

```xml
<id>https://example.com/entradas/energia-solar-001</id>
```

El identificador:

- Debe ser único.
- Debe mantenerse estable.
- No tiene que apuntar necesariamente a un recurso accesible.
- No debe reutilizarse para entradas diferentes.

También puede utilizarse un URN UUID:

```xml
<id>urn:uuid:123e4567-e89b-12d3-a456-426614174000</id>
```

## 3.6. Fechas en Atom

Atom utiliza un formato basado en ISO 8601 / RFC 3339:

```xml
<updated>2026-11-18T12:30:00Z</updated>
```

Partes:

```text
2026-11-18 → fecha
T          → separador
12:30:00   → hora
Z          → zona UTC
```

Con desplazamiento horario:

```xml
<updated>2026-07-15T13:30:00+01:00</updated>
```

En una entrada:

- `updated` indica la última modificación.
- `published` puede indicar la primera publicación.

```xml
<published>2026-11-17T17:00:00Z</published>
<updated>2026-11-18T09:30:00Z</updated>
```

## 3.7. Enlaces en Atom

Atom utiliza un elemento `link` vacío con atributos:

```xml
<link href="https://example.com/"/>
```

### Enlace alternativo

Representa la versión para personas, normalmente una página HTML:

```xml
<link
  rel="alternate"
  href="https://example.com/"
  type="text/html"/>
```

`alternate` es el valor habitual si se omite `rel`.

### Enlace al propio canal

```xml
<link
  rel="self"
  href="https://example.com/atom.xml"
  type="application/atom+xml"/>
```

Permite que una aplicación conozca la URL canónica del canal.

### Enlace relacionado

```xml
<link
  rel="related"
  href="https://example.com/informes/energia-solar"
  type="text/html"/>
```

### Archivo multimedia

```xml
<link
  rel="enclosure"
  href="https://example.com/audio/episodio-01.mp3"
  type="audio/mpeg"
  length="24576000"/>
```

## 3.8. Autores

La información de autor se representa mediante una construcción de persona:

```xml
<author>
  <name>Sara Pérez</name>
  <email>sara@example.com</email>
  <uri>https://example.com/equipo/sara</uri>
</author>
```

`name` es obligatorio dentro de `author`. `email` y `uri` son opcionales.

Puede declararse un autor en el canal:

```xml
<feed xmlns="http://www.w3.org/2005/Atom">
  ...
  <author>
    <name>Equipo de redacción</name>
  </author>
```

O en una entrada concreta:

```xml
<entry>
  ...
  <author>
    <name>Sara Pérez</name>
  </author>
</entry>
```

## 3.9. Categorías

```xml
<category term="Energía renovable"/>
<category term="Análisis"/>
```

Con una etiqueta visible:

```xml
<category
  term="reviews"
  label="Análisis"
  scheme="https://example.com/categorias"/>
```

| Atributo | Función |
|---|---|
| `term` | Identificador de la categoría |
| `label` | Texto visible |
| `scheme` | Sistema de clasificación |

## 3.10. `summary` y `content`

### Resumen

```xml
<summary>
  Explicamos cómo mejoran la eficiencia los nuevos materiales fotovoltaicos.
</summary>
```

### Contenido de texto

```xml
<content type="text">
  Este artículo explica el funcionamiento de los nuevos paneles solares.
</content>
```

### Contenido HTML

```xml
<content type="html">
  &lt;p&gt;Explicamos el avance con
  &lt;strong&gt;detalle&lt;/strong&gt;.&lt;/p&gt;
</content>
```

Cuando `type="html"`, las etiquetas HTML se representan escapadas.

### Contenido XHTML

```xml
<content type="xhtml">
  <div xmlns="http://www.w3.org/1999/xhtml">
    <p>
      Explicamos el avance con <strong>detalle</strong>.
    </p>
  </div>
</content>
```

En este caso:

- Debe existir un único elemento `div`.
- El `div` debe pertenecer al espacio de nombres XHTML.

### Contenido externo

```xml
<content
  src="https://example.com/contenido/energia-solar.html"
  type="text/html"/>
```

## 3.11. Otros elementos del canal

### `subtitle`

```xml
<subtitle>Novedades, análisis y lanzamientos</subtitle>
```

### `rights`

```xml
<rights>© 2026 Horizonte Científico</rights>
```

### `generator`

```xml
<generator
  uri="https://example.com/generador"
  version="1.0">
  Generador LND
</generator>
```

### `icon`

```xml
<icon>https://example.com/img/icono.png</icon>
```

### `logo`

```xml
<logo>https://example.com/img/logo.png</logo>
```

## 3.12. Canal Atom completo

```xml
<?xml version="1.0" encoding="UTF-8"?>
<feed xmlns="http://www.w3.org/2005/Atom"
      xml:lang="es">
  <title>Horizonte Científico</title>
  <subtitle>Divulgación sobre ciencia, tecnología y medioambiente</subtitle>

  <link
    rel="alternate"
    href="https://example.com/"
    type="text/html"/>
  <link
    rel="self"
    href="https://example.com/atom.xml"
    type="application/atom+xml"/>

  <id>https://example.com/atom.xml</id>
  <updated>2026-11-18T12:30:00Z</updated>
  <rights>© 2026 Horizonte Científico</rights>
  <icon>https://example.com/img/icono.png</icon>

  <author>
    <name>Equipo de redacción</name>
    <email>redaccion@example.com</email>
  </author>

  <entry>
    <title>Nuevos avances en energía solar</title>
    <link
      rel="alternate"
      href="https://example.com/energia/avances-solar"
      type="text/html"/>
    <id>https://example.com/entradas/energia-solar-001</id>
    <published>2026-11-18T09:00:00Z</published>
    <updated>2026-11-18T09:30:00Z</updated>
    <category term="Energía renovable"/>
    <category term="Análisis"/>
    <summary>
      Explicamos cómo mejoran la eficiencia los nuevos materiales fotovoltaicos.
    </summary>
    <content type="html">
      &lt;p&gt;Los nuevos paneles destacan por su
      &lt;strong&gt;eficiencia energética&lt;/strong&gt; y su menor impacto ambiental.&lt;/p&gt;
    </content>
  </entry>

  <entry>
    <title>Misión europea para observar el clima</title>
    <link
      href="https://example.com/espacio/mision-clima"/>
    <id>https://example.com/entradas/mision-clima-002</id>

    <updated>2026-11-17T17:00:00Z</updated>
    <category term="Ciencia espacial"/>
    <summary>
      Explicamos los objetivos científicos del nuevo satélite.
    </summary>
  </entry>
</feed>
```

## 3.13. Errores frecuentes

- Omitir `xmlns="http://www.w3.org/2005/Atom"`.
- Usar el mismo `id` para varias entradas.
- Cambiar un `id` después de publicar una entrada.
- Escribir fechas con el formato de RSS.
- Confundir el texto de `link` con su atributo `href`.
- Omitir `updated`.
- Utilizar `content type="html"` sin escapar las etiquetas.
- Usar XHTML sin declarar su espacio de nombres.
- Añadir enlaces relativos en lugar de absolutos.
- Confundir la URL del canal con su identificador.

## 3.14. Ejercicios

1. Crea un canal Atom mínimo.
2. Añade tres entradas con identificadores únicos.
3. Incluye `published` y `updated`.
4. Añade un enlace `self` y otro `alternate`.
5. Añade dos categorías a cada entrada.
6. Utiliza `summary` en todas las entradas.
7. Incluye contenido HTML escapado en una entrada.
