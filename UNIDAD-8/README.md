# Unidad 8. HTML5: estructura, semántica y accesibilidad

En esta unidad aprenderemos a crear documentos web bien estructurados con **HTML5**. El objetivo no es diseñar todavía el aspecto visual de la página —eso corresponderá a CSS—, sino describir correctamente el contenido para que sea comprensible para navegadores, buscadores, tecnologías de apoyo y otras personas desarrolladoras.

## Resultados de aprendizaje

Al terminar la unidad, el alumnado podrá:

- Explicar la función de HTML dentro de una página web.
- Crear documentos HTML5 válidos con una estructura correcta.
- Organizar textos, enlaces, imágenes y contenido multimedia.
- Elegir elementos semánticos adecuados para cada contenido.
- Construir listas, tablas de datos y formularios accesibles.
- Aplicar principios básicos de accesibilidad y posicionamiento.
- Validar un documento y corregir errores de marcado.

## Organización recomendada

- **Sesión 1:** introducción, estructura y texto.
- **Sesión 2:** enlaces, imágenes y multimedia.
- **Sesión 3:** semántica, listas y tablas.
- **Sesiones 4 y 5:** formularios.
- **Sesión 6:** accesibilidad, metadatos y validación.
- **Sesiones 7 y 8:** práctica guiada y revisión.

> HTML indica qué significa cada parte del contenido. CSS decidirá cómo se presenta y JavaScript cómo se comporta.

## Convenciones de código

En los ejemplos se emplean minúsculas, sangrado de dos espacios, comillas dobles y nombres descriptivos. Estas decisiones no siempre son obligatorias, pero facilitan la lectura y el mantenimiento.
