# Unidad 11. Sistemas empresariales: ERP y CRM

Los sistemas empresariales integran información y procesos que, de otro modo, quedarían repartidos entre hojas de cálculo, correos, documentos y aplicaciones aisladas. En esta unidad se estudiarán los sistemas ERP y CRM desde una perspectiva funcional y técnica.

## Resultados de aprendizaje

Al terminar la unidad, el alumnado podrá:

- Diferenciar ERP, CRM y otras aplicaciones empresariales.
- Relacionar módulos con procesos reales de una organización.
- Identificar datos maestros, transacciones, documentos y flujos de trabajo.
- Analizar requisitos y criterios para seleccionar una solución.
- Desplegar un entorno didáctico con Odoo, PostgreSQL y Docker Compose.
- Configurar empresa, usuarios, permisos, productos, contactos y equipos.
- Gestionar un ciclo comercial básico mediante CRM.
- Importar, exportar e integrar datos de manera controlada.
- Definir copias de seguridad, controles de acceso y medidas de protección de datos.
- Interpretar indicadores y evaluar una implantación.
