# Unidad 5. XSLT: transformación de documentos XML

XSLT permite transformar la información almacenada en XML para generar documentos HTML, nuevos documentos XML o archivos de texto. En esta unidad se recuperan los conocimientos de XPath, ya que las expresiones XPath son las que permiten seleccionar los nodos que se transformarán.

```text
XML de entrada + hoja XSLT + procesador → documento de salida
```

## Resultados de aprendizaje

Al terminar la unidad, el alumnado podrá:

- Explicar qué problema resuelve XSLT y cómo se relaciona con XML y XPath.
- Asociar y ejecutar una hoja de transformación.
- Extraer valores, atributos y colecciones del documento de entrada.
- Filtrar, ordenar, contar y clasificar información.
- Utilizar condiciones, variables y parámetros.
- Dividir una transformación en plantillas reutilizables.
- Generar HTML, XML y texto a partir de los mismos datos.
- Detectar y corregir errores frecuentes de transformación.
