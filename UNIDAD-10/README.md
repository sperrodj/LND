# Unidad 10. JavaScript y manipulación del DOM

JavaScript permite añadir comportamiento a las páginas web: responder a eventos, validar formularios, modificar contenido, almacenar preferencias y solicitar datos sin recargar toda la página.

```text
HTML       → estructura y significado
CSS        → presentación y distribución
JavaScript → comportamiento e interacción
```

## Resultados de aprendizaje

Al terminar la unidad, el alumnado podrá:

- Integrar JavaScript correctamente en una página HTML.
- Declarar variables y trabajar con tipos, operadores y conversiones.
- Utilizar condiciones, bucles y funciones.
- Procesar colecciones mediante arrays y objetos.
- Seleccionar, crear, modificar y eliminar nodos del DOM.
- Gestionar eventos de forma accesible.
- Leer y validar formularios.
- Consumir datos JSON mediante `fetch` y `async/await`.
- Guardar preferencias sencillas con Web Storage.
- Depurar errores y evitar prácticas inseguras.
